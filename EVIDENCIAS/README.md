# Evidencias – Infraestructura 1

Esta carpeta contiene las capturas utilizadas como evidencia de la implementación y validación de la Infraestructura 1.

Las evidencias incluyen:

- Topología de red.
- Configuración de direccionamiento.
- Estado de la VPN Site-to-Site.
- Selectores y tráfico RX/TX del túnel.
- Pruebas de ping entre USER y SERVER.
- Prueba de traceroute.
- Pruebas realizadas al deshabilitar y habilitar la ruta VPN.
